### Residual risk

The default query parser changed from `extended` to `simple` in Express 5. TaskHub does not use nested query objects currently, so this is safe. If nested query params are added in future, set `app.set('query parser', 'extended')`.

`express.static` dotfiles default is now `"ignore"` — the `/public` directory has no dot-directories so no impact expected.
