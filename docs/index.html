The problem
Dependency PRs that never land
🔴

CVEs pile up silently

Dependabot raises the alert but can't understand whether your code actually reaches the vulnerable path — so engineers ignore or manually triage each one.

💥

Breaking changes break CI

Major-version bumps introduce renamed methods, removed helpers, and changed signatures. A plain version bump kills the test suite and the PR rots.

🕒

Fixing it is tedious, not hard

Finding 20 call sites, reading the migration guide, applying each recipe, re-running tests — mechanical work that takes a senior engineer half a day.

How it works
Seven steps, fully automated
01

Triage via MCP + OSV

Queries the OSV vulnerability database for the current and target versions, maps every import and member usage in the project, and writes a structured triage.json with the exposure verdict.

MCP tools: osv_lookup · find_usages
02

Read the migration guide PDF

Opens the official migration PDF (or changelog), extracts every breaking change relevant to the actual usage map, and stores them as machine-readable breaking-changes.json.

Skill: breaking-change-extractor
03

Plan

Installs the target version, captures the failing test baseline, then writes a plan.md mapping each breaking change to the exact file and line it affects, with a risk level and fix recipe.

MCP tool: run_checks · fetch_changelog
04

Parallel subagents fix

Spawns one independent subagent per file group. Each agent applies only its own fixes in isolation — no shared state, no merge conflicts. All agents run concurrently.

Bob: spawn_subagent (parallel)
05

Verify with rollback

Runs the full test suite. Failing file groups are retried once. Any group that still fails is reverted and flagged as residual risk — ensuring the final branch is always green or explicitly documented.

MCP tool: run_checks
06

Upgrade Dossier

Generates a self-contained dossier.html and pr-body.md from real measured data — CVEs closed, tests before/after, diff, risk summary — ready to attach to the PR.

Skill: upgrade-dossier
07

Human gate

Presents the full summary and waits. Nothing is committed until a human types approve. Typing reject discards all code changes while preserving all run artefacts.

Bob: custom mode gate
