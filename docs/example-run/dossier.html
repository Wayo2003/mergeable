- router.del('/users/:id', requireAdmin, function (req, res, next) {

bc-005 res.json(status, obj) signature removed app.js
res.json() no longer accepts a status code as the first argument. Use res.status(code).json(obj).

bc-006 res.redirect('back') removed app.js
The magic string 'back' is no longer supported in res.redirect(). Use req.get('Referrer') || '/' instead.

Express 5 requires all wildcards to have a name. Bare /* routes now require a named wildcard like /*splat.

bc-010 req.params wildcard values are now arrays app.js
Wildcard params captured via /*name are now named and may return an array. req.params[0] is replaced with req.params.splat, joined with '/' if needed.

bc-011 req.query is now a read-only getter routes/tasks.js
req.query is no longer writable. Assignments to its properties are not allowed. Local variables are used instead.

bc-013 Optional route parameter suffix ? removed (use braces) routes/admin.js · routes/tasks.js
Express 5 path-to-regexp no longer supports the :param? syntax for optional segments. Braces syntax {:param} / {/:param} is used instead.

+ router.get('/:id{/:field}', requireAuth, ...
