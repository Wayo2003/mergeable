## 🩹 Upgrade: express 4.17.1 → 5.1.0

> Generated by Mergeable on IBM Bob · Run `20260926-154709`

### Security

Both CVEs present in express 4.17.1 are closed by this upgrade:

| CVE | Severity | Summary |
|---|---|---|
| [CVE-2024-43796](https://osv.dev/vulnerability/GHSA-qw6h-vgh9-j6wx) | MEDIUM | express vulnerable to XSS via response.redirect() |
| [CVE-2024-29041](https://osv.dev/vulnerability/GHSA-rv95-896h-c2vc) | MEDIUM | Express.js Open Redirect in malformed URLs |

### Breaking changes handled (9)

- **bc-001** · `router.del()` removed → replaced with `router.delete()`, shim line removed (`routes/admin.js`)
- **bc-004** · `req.param(name)` removed → replaced with `req.params.<name>` at 8 call sites (`routes/admin.js`, `routes/tasks.js`)
- **bc-005** · `res.json(status, obj)` removed → changed to `res.status(status).json(obj)` (`app.js`)
- **bc-006** · `res.redirect('back')` removed → changed to `res.redirect(req.get('Referrer') || '/')` (`app.js`)
- **bc-007** · `res.send(numericStatus)` removed → changed to `res.sendStatus()` at 3 call sites (`app.js`, `routes/tasks.js`)
- **bc-009** · Unnamed wildcard `/*` routes → renamed to `/*splat` (`app.js`)
- **bc-010** · `req.params[0]` wildcard access → changed to `req.params.splat` with Array join (`app.js`)
- **bc-011** · `req.query` is read-only → mutation replaced with local variables (`routes/tasks.js`)
- **bc-013** · Optional param suffix `?` removed → changed to braces syntax `{/:param}` (`routes/admin.js`, `routes/tasks.js`)
